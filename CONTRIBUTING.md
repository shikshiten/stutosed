Thank you for your interest in contributing to **stutosed**!

- You will not replicate, re-host, or distribute unauthorized clones of this codebase or its proprietary streaming pipeline.

## 🛠️ Development Workflow

1. **Fork the Repository** and clone your fork locally.
2. **Create a branch** for your feature or bug fix:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Install dependencies**:
   ```bash
   npm install
   ```
4. **Make your changes** cleanly according to our TypeScript & Tailwind standards.
5. **Verify your build** before submitting:
   ```bash
   npx tsc --noEmit
   npm run build
   ```
6. **Commit & Push** your branch and open a Pull Request.

## 🐛 Reporting Bugs
Please use the [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md) with details on device, browser, and steps to reproduce.
